Welcome to my Week 2 project! This page is made with Python (Flask) and runs behind Nginx, with MariaDB saving the visitor counter.

Visitor counter

This page has been loaded {{ kaynnit }} times.

Database

The visitor counter is stored in MariaDB, an open-source relational database that runs as a service on the server. I created a database called viikko2 with a table called laskuri. It has two columns: id and kaynnit. The app connects with its own user viikko2app, which can only read and update the counter.

How the counter is stored

Nginx receives the request from the browser and every time the page is loaded, app.py connects to MariaDB and runs an SQL command that increases the counter by one. Then it reads the new value and shows it on the page. If it was a variable instead of a database, the value would be gone on reboot. MariaDB saves the data to disk in /var/lib/mysql, which is why it doesn't disappear.

Reboot test

Before the reboot the counter was 12, after sudo reboot all three services (Gunicorn, Nginx and MariaDB) were running automatically. When I reloaded the page, the counter showed 13.
